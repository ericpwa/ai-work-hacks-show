# AI Work Hacks 職場大絕 v0.3｜真實課堂測試 Checklist

測試目標：確認 v0.3 Cloud Ready 可以在真實課堂中穩定支援提交、投票、排行榜、老師管理與課後匯出。

正式網址：

```text
https://ai-work-hacks-classroom.streamlit.app/
```

建議測試人數：先 5-8 人小測，再 15-30 人正式課堂測。

## 1. 測試前設定

- [ ] 使用正式網址開啟系統。
- [ ] 確認畫面顯示「資料後端：Supabase Cloud」。
- [ ] 設定本次測試課堂代碼，例如 `AIHACKS-TEST-0605`。
- [ ] 老師後台 PIN 可登入。
- [ ] 老師後台可建立/更新課堂名稱。
- [ ] 課堂流程可切換為「收件中」。
- [ ] 老師手機也能開啟正式網址。
- [ ] 學生手機至少 2 台可開啟正式網址。

## 2. 學生提交測試

請 5 位測試者各提交 1 筆作品。

- [ ] 每位學生可輸入課堂代碼。
- [ ] 每位學生可輸入學員代碼。
- [ ] 每位學生可填寫作品標題。
- [ ] 每位學生可貼上 `http` 或 `https` 作品連結。
- [ ] 空白必填欄位會被系統阻擋。
- [ ] 非網址格式會被系統阻擋。
- [ ] 提交成功後會看到成功訊息。
- [ ] 作品會出現在「成果展示大廳」。
- [ ] 「最新提交」排序正確。
- [ ] 「看所有人」可看到所有測試作品。
- [ ] 搜尋姓名、組別或作品標題可找到作品。

通過標準：5 筆作品都成功寫入，重新整理頁面後仍存在。

## 3. 投票測試

老師將流程切到「投票中」後測試。

- [ ] 老師後台可切換到「投票中」。
- [ ] 學生未填學員代碼時不能投票。
- [ ] 學生填學員代碼後可以投票。
- [ ] 同一位學員代碼對同一作品只能投一次。
- [ ] 重複投票會出現提醒。
- [ ] 不同學員代碼可投同一作品。
- [ ] 投票後票數會增加。
- [ ] 重新整理頁面後票數不消失。
- [ ] 「星級名人堂」排序正確。
- [ ] 「投影展示模式」能看到最新作品與 Top 5。

通過標準：至少 10 次投票成功，重複投票被擋下，排行榜正確更新。

## 4. 老師後台測試

- [ ] 老師 PIN 錯誤時不能進入後台。
- [ ] 老師 PIN 正確時可進入後台。
- [ ] 可匯出本課堂 CSV。
- [ ] CSV 可用 Excel / Numbers 開啟。
- [ ] CSV 包含作品、投票數、提交時間等欄位。
- [ ] 可隱藏一件作品。
- [ ] 被隱藏作品不出現在學生展示頁。
- [ ] 可恢復被隱藏作品。
- [ ] 可刪除測試作品。
- [ ] 可重置本課堂投票。
- [ ] 可查看所有課堂列表。

通過標準：老師能完成課堂控場、匯出與基本資料修正。

## 5. 雲端持久化測試

- [ ] 學生提交後，老師重新整理頁面，資料仍存在。
- [ ] 學生投票後，學生重新整理頁面，票數仍存在。
- [ ] 老師用另一台裝置開啟同一課堂代碼，資料一致。
- [ ] 關閉瀏覽器再開啟，資料仍存在。
- [ ] Streamlit app 從休眠喚醒後，資料仍存在。

通過標準：資料不因重新整理、換裝置或 app 喚醒而消失。

## 6. 課堂壓力測試

建議在正式課前 10 分鐘做一次快速壓力測試。

- [ ] 10 位以上同時開啟網址。
- [ ] 10 位以上在 1 分鐘內提交作品或測試資料。
- [ ] 10 位以上在 1 分鐘內投票。
- [ ] 頁面沒有大面積錯誤。
- [ ] 老師投影頁可正常顯示。
- [ ] 排行榜在 10-30 秒內可接受地更新。

通過標準：多人同時操作時，沒有資料遺失、沒有系統性錯誤。

## 7. 手機體驗測試

- [ ] iPhone Safari 可開啟。
- [ ] Android Chrome 可開啟。
- [ ] 左側表單在手機上可操作。
- [ ] 作品卡片文字沒有嚴重重疊。
- [ ] 投票按鈕可點擊。
- [ ] 作品連結可開啟。
- [ ] 老師後台在平板或筆電上可操作。

通過標準：學生用手機能完成提交與投票；老師後台建議用筆電。

## 8. 課後收尾測試

- [ ] 老師後台匯出 CSV。
- [ ] CSV 檔名包含課堂代碼。
- [ ] CSV 內容可讀，中文不亂碼。
- [ ] 優秀作品已另存連結或備份。
- [ ] 測試課堂資料可刪除或保留供觀察。
- [ ] 正式課堂資料確認保存政策為 90 天。

通過標準：老師可在課後取得可保存、可整理的成果資料。

## 9. 測試紀錄

請每次測試填寫：

```text
測試日期：
測試地點：
測試課堂代碼：
測試人數：
使用裝置：
是否通過：
發現問題：
需要修正：
```

## 10. Go / No-Go 判定

可以正式上課的條件：

- [ ] 提交測試通過。
- [ ] 投票測試通過。
- [ ] 老師後台測試通過。
- [ ] 雲端持久化測試通過。
- [ ] 至少一輪手機測試通過。
- [ ] 老師已知道如何匯出 CSV。

暫緩正式上課的條件：

- [ ] 多人提交會大量失敗。
- [ ] 投票結果重新整理後消失。
- [ ] 老師後台無法登入。
- [ ] CSV 無法匯出。
- [ ] 學生主要裝置無法開啟網址。
