# AI Work Hacks 職場大絕 v0.3 Cloud Ready｜老師結案交付文件

更新日期：2026-06-05

## 1. 正式上課網址

正式課堂請使用固定網址：

```text
https://ai-work-hacks-classroom.streamlit.app/
```

這個網址部署在 Streamlit Community Cloud，不受教室、Wi-Fi、老師電腦 IP 影響。學生只要能連上網路，就可以用手機、平板或筆電開啟。

## 2. 系統狀態

- 專案名稱：AI Work Hacks 職場大絕 Streamlit MVP
- 版本：v0.3 Cloud Ready
- GitHub repo：`ericpwa/ai-work-hacks-show`
- Streamlit app：`ai-work-hacks-classroom.streamlit.app`
- 資料庫：Supabase Cloud PostgreSQL
- Supabase project：`ai-work-hacks-show`
- 資料保存：90 天
- 本機備援：SQLite fallback

## 3. 老師課前準備

1. 開啟正式網址。
2. 確認畫面標示「資料後端：Supabase Cloud」。
3. 在左側輸入本堂課的課堂代碼。
4. 若沿用預設課堂，可使用：

```text
AIHACKS-0605
```

5. 進入「老師管理後台」，輸入老師 PIN。
6. 建立或更新課堂名稱。
7. 將課堂流程設為「收件中」。
8. 開一個無痕視窗或手機瀏覽器，模擬學生提交一筆測試作品。
9. 確認測試作品出現在「成果展示大廳」。
10. 課前若做了測試資料，請在老師後台刪除或改用正式課堂代碼。

注意：老師 PIN 已在 Streamlit Cloud Secrets 設定。不要把正式 PIN 寫入 GitHub、README、投影片或公開文件。

## 4. 學生操作說明

請老師在課堂投影或 LINE/簡報中提供：

```text
上課互動網址：
https://ai-work-hacks-classroom.streamlit.app/

課堂代碼：
AIHACKS-0605

學員代碼：
請自行輸入，例如 A01、王小明、第一組。
同一位學員請全程使用同一個代碼。
```

學生提交作品：

1. 開啟網址。
2. 輸入課堂代碼。
3. 輸入學員代碼。
4. 在左側「發布成果」填寫展出日期、姓名或暱稱、品牌/職稱/組別、作品標題、作品連結與摘要。
5. 按「發布作品」。
6. 在「成果展示大廳」確認作品已出現。

學生投票：

1. 老師宣布投票開始。
2. 學生在作品卡片先選擇 1 到 5 顆星；已選星星會呈現金色，未選星星維持灰色。
3. 確認星數後，按「送出 X 顆星」。
4. 同一位學員代碼對同一件作品只能投一次。

## 5. 老師上課流程建議

### A. 收件中

用途：學員提交作品、老師確認資料是否正常進來。

老師操作：

- 老師後台 > 課堂流程 > 選「收件中」> 套用流程。
- 投影畫面停在「成果展示大廳」或「投影展示模式」。
- 若學生貼錯連結，可請學生重送，再由老師後台隱藏或刪除錯誤作品。

### B. 投票中

用途：全班觀看作品並投票。

老師操作：

- 老師後台 > 課堂流程 > 選「投票中」> 套用流程。
- 提醒學生使用同一個學員代碼，避免重複身份。
- 可切到「投影展示模式」展示最新提交與 Top 5。

### C. 公布結果

用途：講評、排行榜、成果回饋。

老師操作：

- 老師後台 > 課堂流程 > 選「公布結果」> 套用流程。
- 切到「星級名人堂」或「投影展示模式」。
- 對優秀作品做講評。
- 課後在老師後台匯出 CSV。

## 6. 老師管理後台

入口：頁籤「老師管理後台」。

功能：

- 建立/更新課堂名稱
- 切換課堂流程：收件中、投票中、公布結果
- 匯出本課堂 CSV
- 隱藏作品
- 恢復作品
- 刪除作品
- 重置本課堂投票
- 清理超過 90 天資料
- 查看所有課堂

建議使用方式：

- 課堂中優先使用「隱藏作品」，少用「刪除作品」。
- 刪除作品前先確認已匯出或確定不需留存。
- 重置投票只在測試或重新投票時使用。
- 課後一定先匯出 CSV，再做資料清理。

## 7. 課後收尾

1. 進入老師後台。
2. 點「匯出本課堂 CSV」。
3. 將 CSV 存到本機或雲端硬碟。
4. 檢查是否有優秀作品需要另存連結、截圖或備份。
5. 若本堂課不再需要互動，可將流程切到「公布結果」。
6. 90 天後系統可清理過期資料；重要作品請勿只放在系統內。

## 8. 故障排除

### 學生打不開網頁

請學生確認：

- 網址是否完整。
- 手機是否能上網。
- 是否用了公司或學校過嚴的網路限制。

老師可處理：

- 將網址重新貼到 LINE/簡報。
- 請學生改用手機行動網路。
- 用老師手機測試網址是否正常。

### 學生看不到作品

請確認：

- 課堂代碼是否一致。
- 學生是否真的按下「發布作品」。
- 作品是否被老師後台隱藏。
- 搜尋或展期篩選是否把作品過濾掉。

### 學生不能投票

請確認：

- 左側是否已填學員代碼。
- 是否已經投過同一件作品。
- 是否使用了不同課堂代碼。

### 老師進不了後台

請確認：

- PIN 是否為 Streamlit Cloud Secrets 目前設定值。
- 不要看 GitHub 文件找 PIN；正式 PIN 不應提交到 repo。

### 畫面沒有更新

請嘗試：

- 瀏覽器重新整理。
- 切換頁籤後再切回。
- 老師後台套用流程後等 2-5 秒。

## 9. 安全與資料政策

- 系統只應收集課堂互動所需資訊。
- 學員可用暱稱或組別，不必填真實姓名。
- 不要要求學生輸入電話、Email、身分證、地址、密碼或付款資訊。
- 資料預設保存 90 天。
- 優秀或重要作品由老師課後匯出保存。
- Supabase service role key 只存在 Streamlit Cloud Secrets，不得寫入 GitHub。
